# Desafios Java — Listas e Coleções

Repositório dedicado aos desafios práticos do curso **Java: trabalhando com listas e coleções de dados.**

## Objetivo

Praticar listas e conceitos de orientação a objetos com exercícios simples em Java.

## Desafios

1. Percorrer um `ArrayList` de strings utilizando `forEach`.
2. Trabalhar com herança e casting entre as classes `Animal` e `Cachorro`.
3. Verificar o tipo de um objeto com `instanceof` antes de realizar o casting.
4. Criar uma lista de produtos e calcular o preço médio.
5. Implementar a interface `Forma` em `Circulo` e `Quadrado`, calculando suas áreas.
6. Percorrer uma lista de contas bancárias e encontrar a conta com maior saldo.

## Tecnologias

- Java
- IntelliJ IDEA

## Aprendizados

Prática de `ArrayList`, laços de repetição, herança, interfaces, polimorfismo, casting e `instanceof`.
